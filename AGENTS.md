# AGENTS.md

Руководство для контрибьюторов (людей и агентов) репозитория Tubeloader.

## О проекте

Десктоп-менеджер скачивания видео и аудио из нескольких источников. Минимум — YouTube и Rutube.
Целевое качество — раздельные video+audio потоки с муксингом в один файл.

Текущее состояние: прототип снесён, репозиторий — мультимодульный Gradle-проект с местом под модуль
ядра. Rutube-пайплайн и муксер прототипа сохранены как референсы в `docs/archive/prototype/`.
Приложение переписывается, фронтенд меняется.

## Исследования

Отчёты исследований — `docs/research/`. Один отчёт — один markdown-файл, каждое утверждение
со ссылкой на первоисточник. Отчёты — вход для архитектурных решений, а не их результат.

## Архитектурные инварианты

Не зависят от стека и фронтенда.

- Ядро headless, без зависимостей от UI-фреймворка. Фронтенды тонкие: команды вниз, события вверх.
- Слой презентации (UI-состояние, роутинг экранов) отделён от рендеринга и у каждого фронтенда
  свой; общие между фронтендами — только ядро и доменные типы. UI-компоненты не переиспользуются.
- Источники — плагины за контрактом `SourceAdapter`, роутинг по URL. Новый источник не правит ядро.
- Capability-модель: `Delegate` (адаптер качает сам), `Native` (качает общий пайплайн), `ResolveOnly`.
- Внешние CLI-инструменты (например, yt-dlp) запускаются в отдельном процессе; другой процессной
  изоляции нет.
- Прогресс и ошибки нормализуются в ядре; адаптер отдаёт свои сырые форматы.
- Скачивание идёт через staging, финализация атомарна: в целевом каталоге не бывает полуфайлов.
- У каждого адаптера contract-тесты на golden-фикстурах.

## Стандарты

Правила написания тестов и тестовый стек — `docs/standards/testing.md`; передача ошибок между
швами — `docs/standards/errors.md`; фича-специфичные швы —
Testing Decisions спеки фичи (`docs/features/<feature>/spec.md`).
Стек и роли зависимостей — `docs/tech-stack.md`; версии — `gradle/libs.versions.toml`.

## Вне scope

Маркетплейс плагинов, поддержка «всех сайтов», серверный режим, собственный InnerTube-клиент
в ядре, private-видео (только public и unlisted), аккаунты и синхронизация.

## Agent skills

### Issue tracker

Задачи — локальный markdown в `etc/issues/<feature>/NN-<slug>.md`; человеческий индекс —
`etc/issues/INDEX.md`, обновляется при добавлении, изменении и смене статуса.
См. `docs/agents/issue-tracker.md`.

### Triage labels

Дефолтные пять ролей без переименований. См. `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` и `docs/adr/` в корне. См. `docs/agents/domain.md`.

### Specs

Спека — `docs/features/<feature>/spec.md`, перечисляет свои тикеты в `## Tickets`. См. `docs/agents/specs.md`.

## Заметки

- Референсы снесённого прототипа — `docs/archive/prototype/` (не собираются, не точки входа).
- `etc/`, `build/`, `.gradle/`, `.idea/` игнорируются git.
