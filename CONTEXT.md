# Tubeloader

Десктоп-менеджер скачивания видео и аудио из нескольких источников. Ядро headless,
фронтенды тонкие: команды вниз, события вверх.

## Language

**Source (источник)**:
Сайт или сервис, из которого скачивается контент: Rutube, YouTube. Понятие уровня
бизнес-требований, не код.
_Avoid_: называть «источником» плагин или его код

**SourceAdapter (адаптер источника)**:
Плагин за контрактом ядра, обслуживающий источник или их семейство через внешний
инструмент (yt-dlp). Единственная точка, где ядро касается специфики источника.
_Avoid_: Backend, Plugin, Provider, Driver, Extractor

**Core (ядро)**:
Headless-часть приложения: роутинг URL, оркестрация, нормализация прогресса и
ошибок, staging. Без зависимостей от UI-фреймворка.
_Avoid_: бэкенд, серверная часть

**Extractor (экстрактор)**:
Фаза внутри адаптера: разбор ответа источника в потоки. Только резолвит, не качает.
Нестабильная часть адаптера.
_Avoid_: использовать как имя плагина

**Adapter (конвенция)**:
Адаптером называется только адаптация внешней системы к контракту ядра.
Внутренний перевод интерфейсов — Mapper или Wrapper.

**Staging (стейджинг)**:
Промежуточная зона недокачанного: файлы живут там, пока загрузка не завершена.
Готовый файл попадает в целевой каталог атомарным перемещением.
_Avoid_: качать напрямую в целевой каталог

**Target Directory (целевой каталог)**:
Каталог, выбранный пользователем, куда финализированные файлы попадают из staging.
_Avoid_: библиотека, library

**Progress (прогресс)**:
Нормализованная мера продвижения загрузки: `Indeterminate` (прогресс неизвестен,
например при перекодировании — прелоадер) или `Determinate(current, total)`.

**SourceProgress (сырой прогресс источника)**:
Прогресс в формате источника, отдаваемый адаптером через колбек операции скачивания:
`Indeterminate`, `Absolute(processed, total)` (байты, сегменты, любой счётный шаг) или
`Fraction(ratio)` (доли, 0.0..1.0). Ядро нормализует его в `Progress`.
_Avoid_: смешивать с `Progress` — `Progress` наружу, `SourceProgress` только на границе адаптера

**DownloadStatus (статус загрузки)**:
Фаза жизненного цикла одной загрузки: ожидание, метаданные, скачивание, финализация,
завершено, отмена (включая `Cancelling`, пока идёт остановка), ошибка, прерывание для
проверок, требующих действия пользователя.
_Avoid_: смешивать со степенью готовности — это `Progress`

**DownloadState (состояние загрузки)**:
Пара независимых измерений одной загрузки: `status` (фаза жизненного цикла) и `progress`
(сколько выполнено). Прогресс сохраняется между сменами статуса; поздний колбек
адаптера обновляет прогресс, но не меняет статус.
_Avoid_: хранить прогресс внутри конкретного статуса

**Download Queue (очередь загрузок)**:
Единая очередь постановок: сверх лимита параллельных задач ждут, при освобождении слота
стартует старейшая (FIFO). Владелец жизненного цикла задач, единственное место смены их
состояний.
_Avoid_: scheduler, планировщик, worker pool

**ParseUrl (разбор URL)**:
Операция контракта адаптера: извлекает идентификатор видео из URL и определяет,
принадлежит ли URL источнику. Исходы: поддерживается (id), не поддерживается, не найдено.

**VideoMeta (метаданные видео)**:
Данные о видео от источника: идентификатор, заголовок, автор, длительность, обложка,
доступные качества. Результат операции загрузки метаданных по идентификатору.
_Avoid_: VideoDetails (прототип), смешивать с потоками

**Quality (качество)**:
Один из доступных вариантов видео или аудио для загрузки, выбирается пользователем.

**MediaTool (порт медиаинструмента)**:
Порт ядра для операций над медиафайлами: инициализация инструмента, запуск, прогресс.
Параметры операции задаёт адаптер; сам инструмент адаптер не инициализирует. Отмена
корутины, в которой идёт операция, прерывает её: реализация порта гасит дерево процессов
запущенного инструмента целиком, осиротевших дочерних процессов не остаётся.
_Avoid_: запускать внешний инструмент в обход порта
