# Triage labels

Навыки говорят о пяти канонических триаж-ролях. Здесь — строки, которыми эти роли выражаются
в данном репозитории.

| Роль в mattpocock/skills | Метка у нас | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Мейнтейнер должен оценить |
| `needs-info` | `needs-info` | Ждём информации от репортёра |
| `ready-for-agent` | `ready-for-agent` | Полностью описано, готово для агента |
| `ready-for-human` | `ready-for-human` | Нужна реализация человеком |
| `wontfix` | `wontfix` | Не будет сделано |

Когда навык упоминает роль, брать строку из правой колонки.

Локальный трекер: метка — это строка `**Status:**` в шапке файла тикета.
