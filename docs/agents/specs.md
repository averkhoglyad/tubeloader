# Спеки

Спека — `docs/features/<feature>/spec.md`, один файл на фичу. Её путь не зависит от того, где лежат тикеты.

## Шаблон

Секции: Problem Statement · Solution · User Stories · Implementation Decisions · Testing Decisions ·
Out of Scope · Further Notes.

Конкретные пути к файлам и сниппеты кода в спеку не попадают — устаревают быстро. Исключение:
фрагмент из прототипа, который кодирует решение точнее прозы (машина состояний, схема, форма типа).

## Связь с тикетами

Два обязательных указателя:

- каждый тикет называет свою спеку строкой `**Spec:** docs/features/<feature>/spec.md`;
- спека перечисляет свои тикеты секцией `## Tickets` в конце файла, её дописывает `/to-tickets`.

Обратный ход «спека → тикеты» идёт только через `## Tickets`. Сканирование директорий не требуется.

## Публикация

«Опубликовать спеку» = записать файл `docs/features/<feature>/spec.md`. Статус спека не несёт: триаж-метки
относятся к тикетам. Смена трекера путь спеки не меняет.
